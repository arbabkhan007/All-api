# 06 · Pre-Publish Checklist

Run this on every listing before you hit publish.

## Title

- [ ] 140 characters or fewer
- [ ] Primary keyword sits in the first 40 characters
- [ ] Reads clearly in 3 seconds
- [ ] Doesn't start with the shop name
- [ ] Phrases separated by `|` or `,`

## Tags

- [ ] All 13 slots filled
- [ ] Every tag is 20 characters or fewer
- [ ] Every tag is a 2–4 word phrase — no single words
- [ ] No tag is an exact duplicate of another
- [ ] Tags don't just repeat the title
- [ ] Tags aren't words already covered by category or attributes
- [ ] At least one style tag, one occasion tag, one audience/platform tag

## Description

- [ ] First 160 characters say what it is and who it's for
- [ ] Opening doesn't copy the title word for word
- [ ] File formats listed
- [ ] Sizes and resolution listed
- [ ] What's editable vs fixed is clear
- [ ] Instant-download steps explained
- [ ] Licence and usage rights stated
- [ ] Bullets used, not one solid block
- [ ] At least 3 FAQs answered

## Photos & files

- [ ] First thumbnail is readable at 170×135px (mobile size)
- [ ] One lifestyle mockup, one flat design shot, one "everything included" shot
- [ ] Files uploaded: up to 5 files, 20MB each [2](https://www.insightagent.app/guides/digital-downloads-on-etsy-complete-guide)
- [ ] Listing type set to **Digital** so the instant-download badge shows

## After publishing

- [ ] Check Etsy Stats after 2–4 weeks
- [ ] Replace tags bringing zero impressions
- [ ] Recheck after another 2–4 weeks [1](https://www.insightagent.app/guides/keywords-for-etsy-listing)
