# Etsy Listing Kit — Digital Downloads

A clean, copy-paste kit for writing Etsy listings for digital products (printables, wall art, planners, SVG cut files, Canva templates, event stationery).

Everything in here is built to fit inside Etsy's real character limits, so you can paste without fixing anything afterwards.

---

## The three numbers that matter

| Field | Etsy's limit | Why it matters |
|---|---:|---|
| Title | 140 chars | Etsy weights the **first ~40 chars** most heavily, and mobile cuts titles off around 45–55 chars [1](https://mockupmaestro.com/blog/marketplace-strategy/etsy-seo-guide-2026/) |
| Tags | **13 tags × 20 chars** | Each tag is an independent chance to match a buyer search — an empty slot is a search you never appear in [3](https://loveeattravelrepeat.com/etsy-tags-the-complete-guide-to-seo-visibility/) |
| Description | 10,000 chars | Only the **first ~160 chars** show before "read more" [2](https://typecount.com/blog/etsy-character-limit) |

---

## The whole kit in 8 rules

1. **A tag is 20 characters maximum** — spaces and punctuation count.
2. **Use all 13 tags.** There is no penalty for filling every slot.
3. **Multi-word phrases only.** A single word like `art` or `planner` is too broad to ever rank [3](https://loveeattravelrepeat.com/etsy-tags-the-complete-guide-to-seo-visibility/).
4. **Never repeat a tag.** Etsy already reads the words across your tags and mixes them, so repeating a word wastes a slot.
5. **Cover five angles** — what it is, a synonym, style/aesthetic, occasion or use, and audience [5](https://metadatareactor.com/blog/etsy-seo-complete-guide/).
6. **Don't spend tags on your category or attributes.** Those already act like tags, so use the slots to add *new* words [3](https://loveeattravelrepeat.com/etsy-tags-the-complete-guide-to-seo-visibility/).
7. **Title:** primary keyword in the first 40 characters [5](https://metadatareactor.com/blog/etsy-seo-complete-guide/).
8. **Description:** the first 160 characters say what it is and who it's for — don't just copy the title [1](https://www.listadum.com/blog/how-to-write-good-product-descriptions-for-etsy).

## How to use it

1. Open [02-tag-bank.md](02-tag-bank.md) and take the 13-tag set closest to your product.
2. Swap 3–5 tags for product-specific words from the swap bank in the same file.
3. Build the title with [03-title-templates.md](03-title-templates.md).
4. Write the description with [04-description-template.md](04-description-template.md).
5. Run [06-pre-publish-checklist.md](06-pre-publish-checklist.md) before publishing.

## Quick ways to check a tag is 20 chars or fewer

- **Google Sheets / Excel:** `=LEN(A1)` — must return 20 or less.
- **Anywhere:** paste the tag into a character counter and read the number.
- **By eye:** 20 characters is roughly `two-three short words`, e.g. `printable wall art` = 18.

> Every tag in this kit has already been length-checked. The `Chars` column is the real count, so you can trust it.

## Research method

Tags and limits here come from current Etsy SEO guidance (character-limit references, Etsy's own seller handbook guidance on using all 13 tags, and the standard keyword-research method of harvesting Etsy search-bar autocomplete suggestions) [2](https://typecount.com/blog/etsy-character-limit) [3](https://loveeattravelrepeat.com/etsy-tags-the-complete-guide-to-seo-visibility/) [1](https://www.insightagent.app/guides/keywords-for-etsy-listing).

To refresh any tag set with live buyer language: type your core phrase into Etsy's search bar, note every autocomplete suggestion, then add `a`, `b`, `c`… after the phrase to surface more. Each suggestion is a real search [1](https://www.insightagent.app/guides/keywords-for-etsy-listing).
