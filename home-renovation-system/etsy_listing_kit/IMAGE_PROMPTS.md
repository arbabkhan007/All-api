# Image prompts — every format from one system

Brand locked in every prompt:

- Deep forest `#16352F`
- Warm sand `#E8DDCB`
- Terracotta `#C86B4A`
- Soft ivory `#F8F6F1`
- Sage `#719B7A`
- Charcoal type `#202522`
- Large rounded cards, lots of air, interior-design photography, no corporate blue, no 3D plastic icons, no unreadable lorem.

**Safe zone:** keep the product name, mark, and main number inside the center 70% so the same artwork crops to 1:1, 4:5, 2:3, 3:2, 16:9 and 9:16.

---

## Master style (prepend to every prompt)

```
Premium interior-design editorial photograph, Novality Store brand.
Palette only: deep forest green #16352F, warm sand #E8DDCB, terracotta #C86B4A,
soft ivory #F8F6F1, sage #719B7A, charcoal #202522.
Soft north-window light, linen, white oak, unglazed ceramic, brass, plaster.
No blue UI, no stock-photo grins, no watermarks, no logos of other brands,
no tiny unreadable spreadsheet text (use 3–5 large numbers only).
```

## Crop recipe (one artwork → every frame)

| Frame | Ratio | Use | Crop |
|---|---|---|---|
| Etsy main | 1:1 | Thumbnail | Center square |
| Etsy extra | 3:2 | Desktop | Width full, crop top/bottom |
| Banner / YT | 16:9 | Wide | Width full, crop top/bottom |
| IG feed | 4:5 | Mobile | Center, keep title |
| Pinterest | 2:3 | Pin | Center, keep title + CTA |
| Stories | 9:16 | Reels | Center column only |
| OG / Twitter | 1.91:1 | Link card | Landscape crop |

Always design in 4:5 first, then expand canvas to 16:9 and 9:16 with more ivory — never the other way around.
